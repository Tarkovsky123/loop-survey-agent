# 사람 라벨 입력 방법

두 파일의 `themes` 칸에 응답의 주제를 아래 목록에서 골라 적는다. 여러 개면 `|`로 잇고, 해당 없음은 `-`로 적는다.

| 파일 | 용도 | 주의 |
|---|---|---|
| `heldout_responses.csv` (24건) | **미사용 평가셋.** 모델 출력을 보기 전에 라벨을 단다. 라벨이 끝나기 전에는 모델을 돌리지 않는다 | 24건 모두 채워야 평가가 돈다: `python -X utf8 llm_eval.py --backend codex --tasks heldout` |
| `human_labels.csv` (18건) | 개발용 18건. 주제 정의를 고치는 데 이미 쓴 자료라 참고 수치로만 쓴다 | 채워진 행만 평가에 쓰인다: `python -X utf8 llm_eval.py --backend codex --tasks classify --tag human` |

| 주제 | 뜻 |
|---|---|
| 기기 고장 | 기계·프린터·카메라가 멈추거나 오류가 나거나 수리가 필요함 |
| 고객 감소 | 매장을 찾는 최종 손님이 줄어듦 |
| 콘텐츠 식상 | 프레임·콘텐츠가 비슷하거나 지겨워짐 |
| 가격 고민 | 인화지 값·원가·촬영 가격을 두고 고민함 |
| 확장 의향 | 추가 매장·기기 도입 등 사업을 넓힐 계획 |
| 수요 증가 | 손님·주문·대기줄이 늘어 바쁘거나 기기·렌탈·재고가 모자람 |
| 재고 부담 | 팔리지 않은 재고가 남거나 쌓임 |
| 업태 전환 | 셀프 촬영존 도입 등 사업 방식을 바꾸려는 고민 |
| 배송 불만 | 배송 속도나 상태에 대한 불만 |
| 공급처 변경 | 소모품을 본사가 아닌 다른 판매처(온라인·도매몰 등)에서 사거나 사려고 함 |

예: "기계가 자꾸 멈춰서 손님이 그냥 나가요. 요즘 손님도 줄었어요" → `기기 고장|고객 감소` · "감사합니다" → `-`

**엑셀로 열 때**: 두 파일 모두 엑셀이 한글을 바로 읽는 UTF-8(BOM) 형식이다. `themes` 열만 채우고 그대로 저장하면 된다. 저장할 때 "CSV UTF-8"이든 일반 "CSV"든 상관없다(평가 코드가 둘 다 읽는다). 다른 열은 손대지 않는다.

애매하면 **응답에 직접 적힌 것만** 고른다. 추측해서 주제를 보태지 않는다. 라벨을 단 뒤에는 고치지 않는다(고치면 미사용 평가셋이 아니다).
